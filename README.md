# 雲端搭檔｜三件套入門 (Cloud Trio Lab)

一份適合初學者的繁體中文單頁教學，透過生活例子認識 Cloudflare Pages、Workers、D1 和 Firebase Cloud Messaging (FCM)。

## 開啟教學

直接開啟 `index.html`，或使用 GitHub Pages 網址：

https://cw91020251212.github.io/cloud-trio-lab/

## 功能

- 響應式手機與桌面排版
- 生活化逐步教學與互動工具選擇器
- 分享按鈕（支援裝置分享選單及複製網址後備）
- 彩色 icon 與官方文件連結

圖片資產 `icon.png` 為此教材設計的品牌圖示。
